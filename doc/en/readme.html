Pomodoro Timer for NVDA

A focused-work timer based on the Pomodoro Technique, designed for screen reader users. The add-on announces phase transitions through speech and short tones, so you can stay focused on your work without watching a clock.

Default cycle

  • 25 minutes of focused work.
  • 5 minute short break.
  • After every 4 work sessions, a 15 minute long break instead of a short break.

All durations and most behaviours can be changed in NVDA Settings.

Gestures

All gestures can be rebound from NVDA's Input Gestures dialog under the Pomodoro Timer category.

Default gestureAction
NVDA+Alt+PStart a new pomodoro session, or pause or resume the current one.
NVDA+Alt+SStop the timer and reset the session counter.
NVDA+Alt+TSpeak the current phase, time remaining, and number of completed work sessions.
NVDA+Alt+KSkip the current phase and advance to the next one.
NVDA+Alt+RReset the completed session counter to zero without stopping a running phase.

Phase transition tones

  • Work starts: three-note ascending tone (C, E, G).
  • Short break starts: gentle two-note descending tone.
  • Long break starts: four-note ascending fanfare.
  • Phase finished, waiting for you: a short two-note ding.
  • Timer stopped: two low descending tones.
  • Periodic time-remaining tick: a single soft high ping, played before the spoken time-remaining update.

Tones can be turned off in settings if you would rather rely on speech only.

Settings

Open NVDA menu, Preferences, Settings, Pomodoro Timer. Options:

  • Work duration (minutes) — length of each work phase, default 25.
  • Short break duration (minutes) — default 5.
  • Long break duration (minutes) — default 15.
  • Work sessions before a long break — default 4.
  • Automatically start breaks when work ends — on by default. When off, NVDA announces that work is finished and waits for you to press the start gesture again before the break begins.
  • Automatically start the next work session when a break ends — off by default. When off (the recommended setting) NVDA announces that the break is over and waits for you to press start, so an unattended computer does not silently begin the next work phase.
  • Play tones at phase transitions — on by default.
  • Speak announcements at phase transitions — on by default.
  • Announce remaining time every N minutes — periodic reminder of how much time is left in the current phase. Default 0, which disables the reminder.
  • Play a short tone with the periodic time-remaining announcement — when the periodic announcement is enabled, play a soft attention ping just before the spoken update. On by default. Gated independently of the phase-transition tones, so you can mix and match.

Notes

  • The timer state is held in memory only. Restarting NVDA, or exiting and reopening it, will stop the timer. This is intentional so that a stale timer from yesterday does not unexpectedly fire today.
  • The session counter resets to zero when you press the stop gesture. Use the reset-counter gesture (NVDA+Alt+R) if you want to clear the counter without interrupting a running phase.
  • The timer relies on NVDA being running. If you exit NVDA mid-phase the timer ends with NVDA.
